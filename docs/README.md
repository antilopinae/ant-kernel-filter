## Примерное видение проекта

Разрабатываем асинхронную систему передачи ядерных/ebpf сообщений и их фильтрации.

Задача написать такую библиотеку, которую можно будет подключить к юзерспейсной программе и другому ядерному модулю,
и у них появился бы механизм отправки и фильтрации сообщений между собой.

Ядерный модуль работает постоянно с момента загрузки, независимо от юзерспейсного `ctl`.
Модуль принимает сообщения с других ядерных модулей, фильтрует их и пересылает в юзерспейс.
Когда пользователь хочет, он может через `ctl` выгрузить/перенаправить эти сообщения.

`ctl [kernel|ebpf]` - ручка управления ядерным и ebpf модулем, их загрузка / выгрузка, отладочная информация.
`ctl [prometheus]` - возможность наблюдать за нагрузкой системы фильтрации в разных состояниях и с разными фильтрами.

`ctl [filter]` - система загрузки различных фильтров сообщений вначале в ctl, а потом оттуда в ядерный модуль.
Надо добавить возможность грузить различные комбинации фильтров и их пересечение одновременно.

В ядерном модуле параллельно пополняется битмапа из фильтров для сообщений, но перед этим происходит их (фильтров) валидация.

Задача сделать библиотеку похожей по формату на google-protobuf, добавить ручки-header-ы для управления и подключения этого в другой проект.
